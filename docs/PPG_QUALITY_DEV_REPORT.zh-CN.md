# 腕部PPG候选质量：哪些分数能识别不可靠候选？

2026-10-19 · PPG_QUALITY_DEV1 · 已见开发集探索

本轮找到一个明确的限制：步行中，谷/上升沿/峰次序异常仅覆盖91/1718（5.30%）个参考未匹配候选，修复这种次序问题不足以解释大部分匹配错误。现有窗级质量分数在静坐有排序信息，步行明显减弱。没有删除候选、降低覆盖或选择报警阈值，也没有新的低血糖检测成绩。

## 协议与评价对象

计算前冻结2c1b48c，见[METHOD_PPG_QUALITY_DEV1](METHOD_PPG_QUALITY_DEV1.zh-CN.md)。沿用5名开发受试者、10条记录、211窗和7954候选；只评价首120秒后、固定参考时间核心[4,26)的171窗5119候选。偏移完全沿用上一轮首120秒上升沿校准，不重新优化。

固定三个错误风险分数：非严格次序0/1、峰至上升沿位移偏离该记录校准段中位数的绝对值/MAD（下限1/64秒）、1−原窗级SQI。位移基线只用首120秒PPG，不读尾段或ECG。SQI由已有模板相关性和周期性组成，同窗各候选分数相同。三个方向预先固定，没有翻转低AUC或只呈现最优方案。

阳性为ECG参考辅助一对一匹配中未匹配的候选，不是人工标注伪迹真值。参考时钟、传播时间、整周期偏移歧义、漏/多搏都可能影响这个标签。AUC衡量错误排序，不等于检搏F1、疾病AUC或报警敏感度。

## 全部三个质量候选

活动内先逐记录计算AUC再宏平均。总体每人平均两活动，再按5人重采样10000次；所有30个记录AUC均有两类标签。

|错误风险分数|静坐AUROC|步行AUROC|按人总体AUROC|探索性95%区间|
|---|---:|---:|---:|---|
|谷/上升沿/峰次序异常|0.5153|0.5072|0.5113|[0.5021, 0.5207]|
|峰至上升沿位移偏差|0.7204|0.5085|0.6144|[0.5813, 0.6382]|
|1−原窗级SQI|0.7528|0.5580|0.6554|[0.6196, 0.6958]|

次序异常总体AUC虽略高于0.5，但效应极小。位移偏差在静坐有信息，在步行接近随机排序。SQI在步行仅0.5580，当前证据不足以凭此建立可靠运动质量拒绝器。总体AUC会混合静坐收益和步行不足，不能只报告总体数字。候选分数包含重复窗级SQI，并非5119个独立样本；区间按人估计，仍仅5人且不是外部验证。

全时段每记录峰至上升沿位移中位数的活动平均：静坐96.88ms、步行87.50ms；每记录IQR的活动平均21.88ms、62.50ms。步行离散程度更大，但此描述不能证明运动是唯一原因，更不能从IQR直接设拒绝阈值。

评分核心时间覆盖继续为静坐73.08%、步行70.73%；没有实施质量拒绝。上升沿相邻PPI覆盖仍为60.49%/25.02%，条件MAE仍为25.65/48.35ms。原F1、PPV、参考敏感度及全部三种校准结果保持，详见[上一轮报告](PPG_UPSTROKE_DEV_REPORT.zh-CN.md)。没有事件召回、误报/参考人日、及时性或疾病PPV的新结果，V1–V5失败证据保留。

## 验收与后续决策

独立验证用searchsorted重新匹配171窗5119候选，用阳性/阴性逐对比较复算30个AUC，复核3个按人区间、全部分数/计数/宏平均及4个完美/反向/并列/单类控制。旧上升沿TP/FP/FN逐记录精确复现。工程通过不意味着信号或疾病目标通过；[公开验收JSON](acceptance/PPG_QUALITY_DEV1.json)仅含群体汇总和哈希，逐候选分数留在本地忽略目录。

下一步在原开发范围冻结质量保留率与错误代价分析：若使用SQI规则，阈值只能由校准段分布确定，所有预设工作点都报告，原参考搏与间期分母始终保留。重点量化拒绝会丢掉多少真实搏动/时间，而非追求保留子集的漂亮精度。当前不部署质量拒绝，不据此删除步行、不扩大疾病模型参数搜索。若低质量片段仍难以区分，应回到PPG脉搏一致性/模板特征的定义，而不是仅调一个异常标记。

# PPG-DaLiA：进入心搏/质量基准前的数据审计

2026-10-19，PPG_DALIA_AUDIT1。仅数据与标签结构审计，没有计算检测器成绩。既有V5不重跑。

## 选用原因与已下载内容

[UCI原始发布](https://archive.ics.uci.edu/dataset/495/ppg+dalia)包含15人的64Hz腕部PPG和700Hz胸部ECG。[原始论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC6679242/)说明ECG检测后人工检查修正R峰，E4与胸部设备使用起止双敲击对齐并校正漂移。它适合检查运动条件下脉搏提取；没有本项目的低血糖标签。

本次固定选择静坐/步行两种活动，下载[Charlton的MAT格式版本1.0](https://zenodo.org/records/12793711)。两文件总75,369,564字节，逐文件大小与发布MD5通过，另记录本地SHA256。所有文件留在git-ignored data/ppg_dalia_mat。配置configs/ppg_dalia_audit_v1.json；复查命令`python scripts/audit_ppg_dalia.py`，首次加`--download`。

静坐S1–S15全部存在；步行缺S6，只有14人，不能写成30份完整配对记录。跨活动共同比较使用14人并同时保留15人静坐结果。当前29份记录PPG均有限数值，参考索引均整数、严格递增。仅这些结构检查不能证明波形质量良好。

## 标签与时间的关键限制

- 参考是经过人工检查的**ECG R峰**，不是人工标注的PPG脉搏峰，也不是低血糖事件。PPG脉搏传导和滤波延迟必须处理。
- [活动转换脚本](https://raw.githubusercontent.com/peterhcharlton/info/master/collating_datasets/collate_ppg_dalia_dataset.m)按活动保留首段，重定位R峰，并把心率摘要offset明确标为unknown。因此不能把8秒/2秒HR摘要直接贴到任意PPG短窗。
- 两套索引范围（0-based/1-based）在当前文件中都不越界。范围检查不能确定索引原点。转换流程按MATLAB索引处理；正式评分须明示约定，并报告1/700秒差的敏感性，不能寻找给F1最高的索引后只报最好值。
- 静坐PPG/ECG截段样本长度对应时长最大差约0.0142秒，符合不同采样栅格边缘舍入，但不证明物理脉搏对齐。真实对齐必须另做。
- 仅两个活动不是完整八活动基准，不包含跑步和所有噪声状态。缺S6步行是源文件事实，不能补造数据或按模型成绩移除。

UCI页面及Zenodo派生说明标注原始数据CC BY 4.0；[较早的大学项目页](https://www.eti.uni-siegen.de/ubicomp/home/datasets/sensors19/index.html)仍写科学非商业用途。保留这一来源差异，不将其概括为不受限制的商业数据。当前只做科学研究，本地保留原始数据，公开自写代码与汇总；商业数据再分发不在本项目范围。引用Reiss、Indlekofer、Schmidt及Van Laerhoven原论文、UCI数据DOI与Charlton派生版本。

## 下一阶段的准入与停止条件

1. 固定原V5峰值法作基线，保留其因果滤波、30秒短窗和PPI相邻性规则。先检查参考原点/时间转换，冻结匹配容差、校准片段及评分脚本，再看测试成绩。
2. 用预先固定的S1–S5开发，S6–S15保留验证；按受试者和活动分层。S6无步行在分母表登记。不能随机分重叠窗，也不能利用测试参考选择SQI阈值。
3. 分开报告峰值敏感度/PPV/F1、脉搏间期误差、心率MAE、有效覆盖；SQI拒绝的窗仍计入全参考覆盖。只在可匹配搏动上测PPI误差时，必须同时给匹配比例，避免丢掉坏波形制造小误差。
4. ECG仅用于评分/预定义时间校准，不进入PPG检测器；如用每记录校准参考，报告这是离线参考辅助评价，并同时给固定延迟/未校准敏感性。禁止全测试段最大化对齐后称可部署性能。
5. 正式性能协议和独立评价器尚待冻结；本次只完成数据准入。即便该基准改善，也只是信号子任务进展，不能覆盖V5的1/30失败或宣称低血糖效能改善。

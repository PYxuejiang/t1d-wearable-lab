# 候选级PPG模板与间期：静坐有信息，步行仍不足

2026-10-20 · PPG_LOCAL_DEV1 · 已见开发集探索

新增候选级模板风险在静坐的错误排序AUC为0.8204，高于原窗级SQI的0.7528；步行却为0.5107，低于SQI的0.5580。间期一致性在步行为0.5631，与SQI接近。按人平均两活动后，两项新增分数相对SQI的差值区间均跨零，不能称为稳定总体改善。本轮没有训练疾病模型或筛掉候选。

## 冻结方法

执行前77ca846冻结，[协议](METHOD_PPG_LOCAL_DEV1.zh-CN.md)定义全部计算。只用原5开发人10记录211窗、7954个候选；固定评价171尾窗5119个参考核心候选，沿用已独立复核的未匹配标签及候选索引，不重新选择对齐偏移。

模板只用每记录首120秒PPG候选构建：相邻候选峰中点分段，首末段延至窗口端点；每段插值64点、去均值并L2归一化，逐点中位数后再归一化。风险为1−候选与模板相关性。间期风险取前/后可用上升沿间期相对校准中位数的最大绝对对数比。对照为原1−窗级SQI。没有参考标签进入特征提取，没有融合权重、模型、阈值搜索或方向翻转。

该方法使用后续候选和整窗信息，不是零延迟在线算法。中点分段可能混入邻搏、边界和移动噪声；固定模板可能被校准段噪声污染。间期不规则也不等同伪迹，尤其不能把此质量规则直接当心律异常判定。

## 所有固定候选的结果

AUC阳性是固定ECG参考辅助未匹配候选，并非人工伪迹真值或低血糖标签。每记录计算后活动宏平均；总体每人平均两活动，5人bootstrap10000次。全部30个记录AUC有效。

同一5人开发集已被多轮查看，这些区间不调整多次探索，不能充当确认性证据。静坐改善不能被选择性表述成腕部全天改善；步行两项候选均未展示足够的新信息。

## 覆盖和失败保留

静坐3095候选、步行4859候选全部输出分数；尾段核心分别1969/3150。没有常数形状、零模板或无邻居默认值触发。仅单侧间期的边界候选静坐204、步行218，保留并计入。没有重找峰、删候选、插入搏动或改变参考标签。

原上升沿F1继续为静坐70.16%/步行43.76%；PPI覆盖60.49%/25.02%、核心时间覆盖73.08%/70.73%保持。这些是既有结果，不是本轮新增效果。原低血糖形态方案1/30事件和粗PPG对照3/30等记录不变；本轮没有新的事件召回、误报/参考人日、及时性或疾病PPV。

独立从MAT重新读取波形，手写线性插值、归一化及相关性复算7954候选、10模板和全部风险，用逐对比较复核5119候选的30个AUC及5个按人区间；旧SQI AUC精确复现。合成控制验证幅度/基线不变性、时间同比例缩放不变性和空信息默认值。与生产共享SciPy滤波内核，合成控制重跑生产函数，已在[验收JSON](acceptance/PPG_LOCAL_DEV1.json)披露。波形、个体模板和分数只留本地忽略目录。

## 下一步：先补齐质量标签，而非继续堆同类特征

本轮不支持直接采用新模板或间期规则，也不支持继续扩大这组手工参数。下一步优先审计公开腕部人工伪迹标签及其授权、受试者分组和与已见DaLiA的重合，建立真正的质量标签评价入口；这仍属于PPG信号质量范围，不改变疾病终点。

已核查的具体线索：

- [Segade作者仓库](https://github.com/chengstark/Segade)说明提供30秒PPG与人工二值分割标签，并列出DaLiA、WESAD、TROIKA等评价数据。目录中有模板匹配和深度模型代码，但本轮未复制代码、未下载训练数据，也未确认代码/数据再分发许可。下一步须先审计许可证、文件实际可达性和身份映射。
- [2024模型质量研究预印本](https://www.medrxiv.org/content/10.1101/2024.06.07.24308621v1.full)描述该标签资源共7306段，标签考虑加速度、ECG与PPG观察；初始50段多人校准，其余由单人标注。因此不能把所有标签说成独立多人一致真值。其DaLiA训练受试者与本项目已见队列可能重叠，必须审计，不能冒充新外部验证。
- [腕部质量研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC9370973/)区分可用于心率的基本质量与可用于形态分析的高质量；数据声明为向作者申请。本轮不向作者发消息，也不将该数据当作已取得资源。

以上用于确定下一步审计方向，不把论文成绩移植为本项目表现。未经许可核查和分组冻结，不启动外部模型训练；即使取得人工伪迹标签，也需另行验证对搏动/PPI和低血糖任务的实际增益。

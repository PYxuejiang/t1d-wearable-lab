# PPG_QUALITY_DEV1：腕部候选质量诊断

2026-10-19，计算前冻结。沿用PPG_UPSTROKE_DEV1的5开发人、10记录、211窗、7954候选及首120秒上升沿参考辅助偏移。只读已复核缓存，不重新找搏、选择偏移或扩大滤波参数；不看留出组，不改变疾病模型。研究问题：简单形态异常及现有SQI是否能排序参考未匹配候选，为后续质量机制提供依据。

全部窗按静坐/步行汇总候选数、非严格trough<u<peak次数、峰-u位移的按记录中位数和IQR再活动平均。主要评价仅start>=120且上升沿减固定偏移在[4,26)的候选，参考同[4,26)，匹配容差100ms，沿用原一对一规则；输出TP/FP/FN并精确复现上轮上升沿计数。参考未匹配不等同人工伪迹标签，偏移歧义及漏搏/多搏都会影响它。

固定三个错误风险分数，数值越高预期越易未匹配：①非严格次序0/1；②峰-u位移相对该记录首120秒全部PPG候选的中位数绝对偏差，除以max(MAD,1/64秒)；③1−旧窗级SQI，每个候选继承所在窗分数。校准中位数/MAD只读PPG，不能输入尾段或参考标签。不给任何方案选择阈值，不删除或拒绝候选、不翻转负向AUC、不训练模型。

每记录以未匹配为阳性计算三个AUROC（并列半分），分别活动宏平均，再每人平均两活动并5人bootstrap10000次、种子20261019给95%探索性区间。若某记录单类，AUC记空并公开有效记录/人数，不能静默删除；总体区间仅完整两活动的人并报告人数。本实验候选加权而非等窗口加权；同窗SQI重复，按人聚合仍只有5人。

另外报告次序异常占所有尾段候选比例、异常候选未匹配率、异常覆盖所有未匹配的比例、严格次序候选未匹配率、参考漏匹配率。公开按记录宏平均与活动总计数，不公开个体结果。即使异常全部解决，异常只覆盖少部分错误时也不能据此假定性能大幅提升；这只是错误构成描述，无删除后性能或反事实疗效。

固定核心时间覆盖和PPI覆盖/条件误差沿用上轮，不构造“高质量子集”新成绩；没有事件召回、误报/人日、及时性、疾病PPV的新估计。全部记录保留，所有三个候选均报告，不挑最佳AUC作为有效性结论。独立验收重新匹配每窗、复算分数、用成对计数复核AUC、复算按人区间和旧计数。个体候选分数/匹配标识只入ignored outputs。公开汇总、代码、报告、卡片与数据源哈希。

# PPG_UPSTROKE_DEV1 腕部独立候选的峰与上升沿诊断

2026-10-19，运行前冻结。只用原PPG-DaLiA开发S1–S5，静坐/步行10记录、211个30秒窗；不读取留出组成绩、不改变疾病模型。全部属于已见开发集探索。数据、参考R峰索引、连续0.5–5Hz三阶Butterworth因果滤波沿用PPG_CAPTURE1，窗口候选峰复用其v5_peaks；不重新选频段、prominence、SQI或受试者。

对每个PPG候选峰p（样本索引），搜索左界为max(2秒索引, p−ceil(0.4fs), ceil((上一个候选峰+p)/2))，首峰无中点项；峰前这一范围内（含p）最低幅值为谷，同值取最早。谷至p内最大中心差分为u，同值取最早。规则只读PPG，不输入ECG、人工边界或标签。所有候选均输出u，谷/u/峰次序异常只计数不删除；中点分界保证不同候选的搜索段不重叠。时间戳转换保持64Hz，无指端常数补偿。中心差分和整30秒窗口含等待，不能声称零延迟在线。

比较两个标志（峰、u），分别用首60秒、第二60秒、首120秒ECG参考在±1.5秒、10ms网格内独立估计固定相对偏移（旧select规则：最大±100ms一对一匹配数，同分最近0.2秒再较小值）。仅校准段选择，尾段>=120秒冻结。所有评分使用相同参考时间核心4≤t<26秒，原窗口和全部记录保留。远离所选偏移≥0.3秒的最佳竞争点若匹配比≥0.95记歧义，其距离/参考RR中位数接近整数±0.15周期单独计数。此为参考辅助匹配，不是独立物理时钟或上升沿人工真值。

预设主要比较：首120秒校准后，u减峰的尾段F1和相邻PPI覆盖差，各人先平均两活动，再5人bootstrap 10000次，种子20261019。报告全部三个校准段、两标志、两活动的宏F1/PPV/敏感度/条件PPI MAE/PPI覆盖、固定核心时间覆盖、歧义数；另外报告两一分钟校准差≤100ms记录数和尾段F1平均绝对变化。不选胜者、不因结果调窗口、不将未匹配间期排除出覆盖分母。主差区间跨零或PPI覆盖变差不得说可靠改善。

# BUT_ADAPTER1：跨版本小样本读取协议

冻结于首次下载波形前，2026-10-20。延续BUT_SOURCE1，仅验证原始PPG读取，不训练、评分或选择通道。

- 固定四条：初版首尾100001、111004；扩展版首尾112001、149108。来自上阶段结构抽查，非按质量或模型成绩选择。全部结果报告。
- 只取对应PPG.dat和已缓存头；使用2.0.0官方S3镜像及已缓存官方SHA256清单核验。原始记录留outputs，不上传。
- 自写受限WFDB格式16读取器；逐通道增益/基线转换，保留RGB所有通道、符号与时间顺序，不使用参考HR/Quality。只接受同文件、无偏移、无skew、无多采样因子的格式16，其他显式失败。
- 用独立WFDB Python 4.3.1读取原始头/波形比较：shape、fs、数字样本完全一致；物理值最大绝对误差≤1e-10，NaN掩码一致。记录文件完整性、有限值、数字缺失/削顶计数、单位和布局，不输出样本值。
- 扩展版预期标准形状300×3、30Hz，三通道全部保留。初版若仍为1×300，只报告原始标准布局；允许显式“legacy候选转换”用于独立检查数值不丢失，不能据此声称时间顺序得到生理验证或进入训练。没有来源证据时保持legacy训练准入待定，不静默删48条。
- 工程验收：4条全部下载哈希一致、两个读取器数字/物理值通过、合成负增益与RGB交织测试及错误格式/长度拒绝测试通过。原始布局成功不等同所有3888条导入成功。
- 发现任何不一致保留失败，先修读取器并记录原因，不更改原始头或原始记录来迎合解析。允许修自写代码，不能改变本协议样本/容差或选择更好通道。
- 下一阶段须先核验旧版重排的来源证据，再按人冻结模型划分。手机质量效果不等于腕部外部验证；不影响V1–V5疾病指标。

依据：[官方数据版本](https://physionet.org/content/butppg/2.0.0/)、[WFDB头规范](https://physionet.org/physiotools/wag/header-5.htm)、[WFDB格式规范](https://physionet.org/physiotools/wag/signal-5.htm)。作者在[2021年答复](https://www.mathworks.com/matlabcentral/answers/871363-how-can-i-read-a-dat-and-hea-file-in-to-matlab#answer_782259)建议使用WFDB工具箱；该答复没有解决本轮发现的旧版时间轴问题，不能作为reshape正确的证明。

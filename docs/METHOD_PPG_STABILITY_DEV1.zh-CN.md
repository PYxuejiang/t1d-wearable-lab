# PPG_STABILITY_DEV1：校准稳定性与周期歧义

2026-10-19，执行前冻结。仅PPG-DaLiA已有开发集S1–S5，10活动记录；复用PPG_CAPTURE1缓存，不重新提峰，不评分其余人，不训练疾病模型。

三个固定校准段：0–60秒、60–120秒、0–120秒。分别在−1.5至+1.5秒、0.01秒网格选最大一对一匹配数；同分先接近0.2秒、再较小值。各段选出的偏移固定用于相同的120秒以后尾段，评分核心统一4–26秒，匹配容差100ms。不根据尾段结果选择三者中的胜者。

所有10记录保留，三个方案均报告F1、PPV、灵敏度、相邻PPI可匹配比例与条件误差，以及评分核心时间覆盖。校准稳定定义为前后两段偏移绝对差≤100ms（诊断标记，不是质量拒绝）。报告尾段F1对两种一分钟校准的绝对差及5人bootstrap区间，避免正向差被误读为新增算法效果。

每校准段保留距离最优值至少300ms的最强竞争偏移，竞争匹配数达到最优95%标为歧义。记录竞争偏移差/校准参考RR中位数，与最近非零整数距离≤0.15时标为“接近整搏周期”。这是解释性诊断阈值，不确认真实时钟，也不据此扣除一整搏。边界候选与所有不稳定记录均保留。

合成控制：不等间隔心搏的固定已知偏移、严格周期心搏的多解，以及前后一分钟偏移改变的情况。所有控制不代表真实腕部准确率。

验收：缓存哈希和开发范围通过；30次校准选择及30组尾段计数由独立实现复核；所有方案参考分母和机会相同；公开仅活动/群体汇总与合成控制，偏移和逐窗结果只在ignored outputs。通过只意味诊断可复核，不表示低血糖报警有效。

# 交互手表展示：设计、资产与验收

日期：2026-10-18。这是现有本地展示站的产品叙事改版，未部署公网服务。

## 交付

以参考图的大尺寸产品、米白留白和紫色金属质感组织首页；参考Apple产品页的简洁层次，模型为自写原创，不使用品牌标志或外部产品资产。首页只保留本轮命中、覆盖两项必要指标，误报和区间折叠；完整看板保留在`#research`。

- 工作、生活、睡眠三场景，合成表盘数值和时间随场景改变。
- 日常→采集→处理→识别→提醒五步，可手动选择或自动播放，每步6.5秒，最后停止；可暂停。
- 表背光学PPG与运动ACC高亮、常规/侧面/传感器角度、指针旋转、屏幕分层、光学呼吸灯。
- 合成带噪/处理后波形；0.5–5Hz带通、30秒短窗、质量/形态/PPI、训练期归一化、LR/ExtraTrees/HGB及验证阈值的原理说明。
- 心率、呼吸、血糖分别说明证据边界；提醒只改变演示界面，可以确认，不调用通知服务。
- 暮光紫、月光银、深海蓝三色，当前颜色GLB下载。支持键盘按钮、可见焦点、减少动态偏好及WebGL不可用时的静态替代。

## 模型来源与复现

`showcase/src/watch-model.js`生成圆角表壳、表冠、表背光学组件与运动芯片示意；`showcase/scripts/export-watch.mjs`导出GLB。三个文件各约519KB、6,360三角形，哈希/字节数见`showcase/public/models/manifest.json`。自写源代码和模型MIT；Three.js同为MIT，依赖锁文件纳入版本控制。

这是程序化几何与PBR材质，没有执行Blender/Keyshot转换、减面或纹理烘焙。表盘CanvasTexture在浏览器生成；下载GLB保留静态材质和组件，动态表盘与流程由网页代码驱动。光学及ACC的位置是讲解示意，不能据此制造医疗设备。

```powershell
cd showcase
npm ci
node scripts/export-watch.mjs
npm run build
npm run dev
```

无远程字体/HDRI依赖；字体采用本机回退。3D和旧研究图表分别延迟加载。Three.js与ECharts分包仍分别超过500KB构建提示；当前未完成低端手机性能实测，不能声称达到某个帧率。渲染像素比上限1.65，页面隐藏或组件不在视口时跳过渲染。缩减动态时关闭浮动/呼吸与CSS动画，角度即时切换。

## 科学边界

动画全部为合成讲解，未接入患者波形、真实传感器或医疗通知。心率/呼吸异常尚未专项验证；PPG不是血糖传感器，模块二用CGM作参考。V5形态方案1/30命中、前15分钟0/30，粗特征3/30，覆盖72.8%、误报0.718次/参考人日，仍失败。工程页面验收不改变检测结论。详见[PPG报告](PPG_MORPHOLOGY_REPORT.zh-CN.md)与[目标复核](GOAL_REVIEW.zh-CN.md)。

下一次每小时接续：先读最新计划与实际进程，不重跑V5；仅在PPG方向审计有标注基准，冻结信号提取/质量验证后再执行。首页不是新的医疗产品或已完成的临床成果。

## 2026-10-23 首屏加入健康 Agent 叙事

首屏直接呈现“手表感知，Agent 理解”：保留原有原创手表、场景、采集、信号处理、指标解释和提醒确认，在原五步中插入独立 Agent 步骤，形成日常→采集→处理→Agent→识别→提醒六步。右侧常驻合成个人记忆卡与目标、同设备14天基线提示；表体旁展示从信号、记忆、工具/依据到日报的连接，并可一键进入 Agent 过程或完整健康工作区。原场景描述仍可展开查看。

Agent 步骤有四个可切换阶段：读取记忆、工具分析、检索依据、整理日报。可单独播放，也随完整旅程自动推进；表盘与所选阶段同步。示例分析使用共享 `analyzeDay`，三场景日摘要与观察保持一致，不将表盘瞬时示意心率混同为日静息心率。来源阶段提供 FDA、PHIA、PhysioLLM 原始链接与用途说明；全部为合成演示，不发真实模型请求，不宣称后台已在采集或诊断。真实持久记忆与模型运行仍需要私有后端，见 [接入说明](HEALTH_AGENT.zh-CN.md)。

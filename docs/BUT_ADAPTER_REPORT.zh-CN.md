2026-10-20 · BUT_ADAPTER1 · 固定小样本工程验证

首次取波形前以提交96e0162冻结[协议](BUT_ADAPTER_PROTOCOL.zh-CN.md)、自写读取器和7项合成测试。两个发布阶段各自首尾共4条记录全部保留；8个头/波形文件均通过官方SHA256。自写读取与独立WFDB 4.3.1的数字样本逐值一致，物理值最大绝对误差为0，全部2400个值有限，数字缺失码计数0。

这证明四条样本的数值读取一致，不能证明旧版300个“通道”就是按时间排列的300点，也不是全库或模型性能验收。

## 实际发现与保留的失败

第一次真实数据校验在单位字段比较处失败：源头中的`a.u.`被WFDB 4.3.1解析成`a`。检查其`wfdb/io/header.py`的单位正则可见不包含点号。自写读取器保留原始单位；第二次校验把该差异明确存为`unit_metadata_equal=false`，继续协议中既定的数字/物理值核验，没有修改源头、样本或误差容差。不能宣称两读取器所有元数据均一致；WFDB解析出的后续描述字段也不用于本项目通道识别，RGB名称来自原始头。

在新版两个样本中共6个数字值等于32767。这里仅记录编码端点计数，不据此判定硬件削顶或将片段删掉；缩放到整数范围也可能出现端点。质量标签与参考HR未用于本轮适配或选择。

读取器只支持已声明的两种BUT布局及同文件交织的普通16位小端数据，逐通道应用基线和增益。遇到偏移、skew、不同采样因子、未知布局或长度不一致时显式拒绝。合成测试覆盖RGB交织、负增益、缺失码、legacy形状保持、截断文件及4种不支持的格式，避免将错误布局“读成功”。

## 复核和复现

- [读取器](../src/t1d_lab/but_ppg.py)、[合成测试](../tests/test_but_ppg.py)、[固定样本运行器](../scripts/run_but_adapter.py)、[汇总JSON](acceptance/BUT_ADAPTER1.json)。
- 独立读取器固定`wfdb==4.3.1`，安装于本地忽略目录`outputs/adapter_tools`，未修改全局Python依赖；NumPy1.26.4。标准格式依据[WFDB头规范](https://physionet.org/physiotools/wag/header-5.htm)及[数据格式规范](https://physionet.org/physiotools/wag/signal-5.htm)。
- 先运行BUT_SOURCE1取得标签/索引与校验清单，然后执行`python -m pip install --no-deps --target outputs/adapter_tools wfdb==4.3.1`，再运行`python scripts/run_but_adapter.py`。依赖需已具备本项目环境及WFDB所需运行库；已有完成缓存会拒绝重复运行。
- 原始波形仅在`outputs/but_adapter_v1`，不上传、不展示。两个读取器共享NumPy基础数组环境，但WFDB自行解析源头和数字样本；自写读取器不调用WFDB实现。

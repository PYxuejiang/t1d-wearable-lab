# PPG_FIDUCIAL1：专家边界内的峰与上升沿条件定位

2026-10-19，计算前冻结。仅PPG-BP固定v1的219短信号，哈希沿用来源审计。既有标签审计已查看全队列，故本研究为该资源上的探索性实验，不声称新的独立外部验证。

按sha256("PPG_FIDUCIAL1/"+条目名称)排序，前70为开发、剩余149评价；排序仅依名称不读波形或标签结果。每条MG专家os起止边界是明确输入，参考pk和u不能进入定位函数。不能把专家帮助选中的单搏当作连续PPG检出。PC参考按其自己的有效os选择唯一pk；缺失/歧义保留为不可评价，不静默取第一峰。

固定三路：raw（原提供信号不加滤波）、causal5（3阶Butterworth 0.5–5Hz因果sosfilt，起始零状态，作为现有链路频段的条件定位基线）、offline12（3阶Butterworth 0.5–12Hz双向sosfiltfilt，SciPy默认padding，作为离线形态对照，不称pyPPG复现）。整段处理后，在MG边界内取最高幅值作为峰；用中心差分np.gradient计算导数，在起点至预测峰之间取最大导数作为u；所有同值取最早。单位秒，索引round(t*fs)且右端不含；无任何按标签时移或滤波延迟校正。

开发期以MG峰和u的绝对误差均值等权相加取平均，选最低者，同分按raw、causal5、offline12顺序。选定后锁定，不按评价集或PC选择。全部三路开发与评价成绩公开；不删坏例、不设SQI拒绝。

各路分别报告MG/PC的pk与u MAE、中位和95分位误差、偏差、≤10/20/50ms比例及评价条数/149（开发条数/70）；另报成功输出占所有条目与边界顺序。选中方案对causal5，在相同评价条目上报告按条目配对MAE差及10000次bootstrap区间，种子20261019，两标注者分别给出。这是一个精选心搏/人的条件任务，不能报告连续时间覆盖、事件召回或疾病PPV。

验收：主程序拒绝覆盖结果；独立MAT解析和极值复算核对所有输出、参考映射、开发选择、群体指标与bootstrap；所有219分母留在记录中。个体预测和标注只在ignored outputs。公开只含群体结果、冻结源哈希和合成控制。无新低血糖模型或腕部迁移。

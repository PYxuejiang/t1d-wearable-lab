# PPG人工特征点标注：入口与文件结构审计

2026-10-19。为分离“PPG本身定位错误”和“ECG/PPG相对时间错误”，已取得作者公开的[pyPPG benchmarking v1标注包](https://zenodo.org/records/10523285)。作者说明包含两名独立标注者对PPG-BP的特征点标注；[验证文档](https://pyppg.readthedocs.io/en/latest/PPG_validation.html)介绍标注者一致性和算法对照流程。

本地只下载7,172,151字节的PPG-BP_annot.zip，官方MD5 `1b03371ca9cfad39ab7209425673b351`核对通过。Zenodo v1 API声明开放、CC-BY-4.0；这是该数据记录的许可，不能直接套用于pyPPG算法代码。另有v2记录10677964，但其列出的是results.zip，故本次明确固定含标注包的v1，未下载作者算法结果或拿其成绩作为本项目成绩。

## 实际文件核查

- ZIP内7084文件，包含6576个MAT；不代表7084名患者或6576条独立波形。
- 219个唯一命名信号条目；两份汇总标注集合各219条，名称均能与信号一对一关联。
- 采样率1000Hz，波形长2.1–4.2秒，样本均有限值。
- 共同标注字段含pk、os、u、dn及导数特征点；具体单位、索引起点、空标注和标注者差异尚待审计。

数据只保存在ignored `data/ppg_bp_annot`。公共[结构验收](acceptance/PPG_BP_ANNOT_SOURCE1.json)仅含哈希、数量、字段和待办，不发布条目名称、个体信号或标注坐标。`scripts/audit_ppg_bp_annotations.py`可重跑结构核查，不重复下载、不执行包内代码。

## 适用边界和执行次序

这批是短片段、直接PPG特征点验证候选，不是连续腕部活动基准，更没有低血糖标签。现有要求至少20秒且丢弃起始2秒的30秒检测器不能原样套用；也不能通过拼接/复制短片段来伪造独立长记录。

下一步先核对原始来源、采集部位、标注所用预处理、时间/索引约定和两名标注者一致性，再冻结短片段定位协议。开发与评价条目必须隔离，算法定位不可读取标注坐标；如果使用专家给定的单搏边界，必须称为条件定位任务，不能当作从连续PPG检出心搏的敏感度。

随后在既有PPG-DaLiA开发集检查峰/上升沿、校准平台与残差的稳定性。人工PPG标注可作为新的定位依据，但其数据域成绩不能直接移植到腕部或低血糖目标。

# 三分钟演示脚本与运行方式

直接展示公共汇总结果不需要下载原始数据。建议使用 Node 22；Python 分析建议 3.11/3.12。

```powershell
cd showcase
npm ci
npm run dev
```

打开命令打印的本地地址。站点包含项目总览、协同预测、传感器实验、验收证据；静态结果、PNG/SVG 卡和源哈希已在仓库中。原始数据、个体预测和回放轨迹不在公共代码中。

如需本地真实回放/波形，先按 README 完成数据分析，再运行：

```powershell
python scripts/export_showcase.py
python scripts/export_signal_example.py
python scripts/export_cards.py
```

|时间|页面与操作|讲解重点|
|---|---|---|
|0:00–0:30|总览；说明两个模块|研究健康算法与传感器方案；流程通过和效果达标分开|
|0:30–1:05|协同预测；切换 LOSO/未来时间留出|20 人、未来 30 分钟；CGM 基线改善，腕部附加信息未达目标|
|1:05–1:30|载入本地回放、步进、暂停；勾选事后结局|先隐藏未来参考，预测在当时可得信息下发出；示例不代表总体成绩|
|1:30–2:00|传感器实验；切换五个配置、载入真实波形|7/10 人通过时钟审计；当前检测失败，零误报不能掩盖零召回|
|2:00–2:30|验收证据；展开 S1b/S3，Esc 关闭|排除与缺失公开；独立复算事件匹配；不将检测延迟称为提前量|
|2:30–3:00|导出成果卡；下载证据 JSON|展示实际结果、运行标识和边界；下一轮先解决 SQI/时钟/外部验证|

键盘可操作导航、开关、滑块和证据抽屉；抽屉支持 Esc 和焦点返回。系统减少动态效果设置会关闭图表及 CSS 动效；回放有暂停按钮。390px 窄屏与桌面已核对，无横向溢出。公开仓库缺少本地轨迹时显示空状态，不以模拟成绩替代。

本文件是录屏操作脚本；仓库没有声称提供已完成的三分钟实时录屏。成果卡和静态截图已生成，可直接用于作品介绍；录制可以在本地演示时按以上时间线进行。

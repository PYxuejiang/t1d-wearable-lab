# PPG_LOCAL_DEV1：候选级模板与间期一致性

2026-10-20，运行前冻结。PPG_RETENTION_DEV1已否定现有窗SQI简单整窗筛选。本阶段只问新增候选级信息能否区分参考未匹配，不实施拒绝、不修改找搏或疾病模型。仅原5开发人10记录，211窗、7954候选，保持171尾窗5119核心候选及上一轮固定参考标签。

复用既有候选峰、上升沿和0.5–5Hz三阶因果PPG滤波，不调频段/参数。每候选峰的波形段由相邻峰中点界定，第一/末候选以0/最后采样点界定。取ceil左界至floor右界包含端点，等距插值64点，减均值并以L2范数归一化。每记录首120秒全部候选的归一化形状逐点中位数，重新去均值/L2归一化得到固定模板；不挑“好搏”、不输入ECG。尾段模板错误风险=1−形状与模板点积（理论[0,2]）。近常数形状或模板（范数<=1e−12）记风险2并计数，不删除。

每候选用所在窗可用的前后上升沿间期，取max(abs(log(interval / calibration_median_interval)))为间期风险；校准中位数仅首120秒各窗内全部正间期，不跨窗。首末候选仅有单侧间期，必须计数并保留。若无有效邻间期，风险2并计数；此默认值固定且不是生理阈值。使用后一候选和完整窗口，含未来信息与等待，不声称零延迟实时。

固定三个风险：模板、间期、原1−SQI。没有模型、融合权重、符号翻转或阈值选择。评分仅用PPG_QUALITY_DEV1已独立复核的候选索引/未匹配标签，新增特征提取不读参考；验收要精确复现原SQI AUC。标签为固定ECG参考辅助匹配而非伪迹真值。中点形状可能混入邻搏/移动噪声，校准模板也可能被噪声污染，本次必须如实报告失败。

按记录AUC、活动宏AUC、有效记录数、总体每人平均两活动的AUC及95%区间全报告；模板减SQI、间期减SQI两个预设差值按5人bootstrap10000次，种子20261020；若单类则空值并报告完整人数。不能只挑静坐或最佳特征做总体有效声明。不删除不匹配搏、不新报保留子集效果；旧F1、PPV、PPI覆盖、时间覆盖和疾病指标均不改变。

独立验收重新从MAT读取滤波波形，独立线性插值/归一化计算所有候选与模板，复算全部风险分数；对5119尾候选用逐对比较AUC（不同于生产rank-sum），复算3个总体AUC区间和2个差值区间。合成控制：平移/正幅度缩放形状不变、所有时间等比例缩放间期风险不变、零形状/无邻居有明确默认值。公开仅活动/群体聚合，个体模板、波形、分数与标签只入ignored outputs。

# 检测改进报告

运行标识：`improve-32b0b8f73297`。原始失败证据未覆盖；下列新实验均单独保存。

## 初步正向效果与不能越过的边界

新公开手表队列个体化实验，比较同一个人的相同测试行：纯时间基线平均 AP **0.0980**，穿戴信号+时间 **0.1887**。8 名测试期有正类的受试者配对 AP 差值 **+0.0907**，按人 2,000 次 bootstrap 的探索性 95%区间 **[0.0024, 0.1845]**。这是排序能力的候选改善；比较未作多重校正，不是确认性统计结论。另3人的测试期只有单类，AUC/AP记NA，仍保留其混淆矩阵和特异度。

穿戴+时间 AUC 为 **0.6131**，相对纯时间基线的差值区间跨零。验证阈值下平均点敏感度 **21.2%**；各人结果差异大，不能作为可靠低血糖报警器。没有宣布80%事件召回目标达标。

公开 CSV 缺日期/完整时间戳，采用原始行顺序前60%训练、中20%验证、末20%测试，边界两侧各删除120行。**不是已确认的前瞻性时间验证**，没有把行号换算成观察人日或事件时长。按小时与连续分钟行网格的一致性另作预先列出的99%子组检查；它不能排除整日缺失，也不用于挑选总体最优成绩。

模型不输入CGM、源低血糖标签、IOB或饮食记录；训练/验证内选择学习器和分类阈值。源数据的状态标签采用作者定义及参考回填，和PhysioCGM源`<70mg/dL`事件终点不同。该结果不能与PhysioCGM直接做传感器增益相减。

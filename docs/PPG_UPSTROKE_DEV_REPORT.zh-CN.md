# 腕部 PPG 峰与上升沿：开发集诊断

2026-10-19 · PPG_UPSTROKE_DEV1 · 已见开发集探索

完成了不依赖人工搏动边界的上升沿定位。首120秒校准下，静坐F1从58.71%提高到70.16%，相邻PPI覆盖从46.00%提高到60.49%；步行F1从47.60%降至43.76%，PPI覆盖从27.54%降至25.02%。这支持继续研究静态信号的形态信息，但不支持全场景替换原峰检测，也没有产生新的低血糖识别结果。

## 方法与复现

运行前协议及代码冻结于c835357，见[METHOD_PPG_UPSTROKE_DEV1](METHOD_PPG_UPSTROKE_DEV1.zh-CN.md)。仅原PPG-DaLiA开发S1–S5，静坐/步行10记录、211个不重叠30秒窗；旧峰候选7954个全部保留。连续0.5–5Hz因果滤波后，在每个峰前最多0.4秒且不越过相邻候选中点的范围找谷，再找最大中心差分。无需人工单搏边界，不输入ECG进行定位。243个候选的谷/上升沿/峰不是严格先后关系，未删除。

峰与上升沿分别在0–60、60–120、0–120秒按ECG参考估计偏移，尾段固定>=120秒；相同参考时间核心4≤t<26秒，全部记录保留。ECG只作参考辅助匹配，不能据此证明物理同步，也不属于上升沿人工真值。三校准方案全部报告，没有按尾段选最优方案。完整聚合与源码/输入哈希见[验收JSON](acceptance/PPG_UPSTROKE_DEV1.json)。
